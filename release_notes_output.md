# Shopping App 1.2.0 release note

Release date: 2026-10-03

## Customer Storefront Updates

### New Features

- Added 'Dark mode' in Settings.

- Added a option to add items to 'Wishlist'.

### Improved Features

- Optimized loading of product pages.

### Removed Features

- Removed the 'Compare Products' tool.

## Merchant Portal Updates

### New Features

- Added real-time settlement tracking and payout export tool.

- Added support for credit card payments during checkout.

### Improved Features

- Optimized loading merchant dashboard.

### Removed Features

- Removed payment by cheque for payouts.
